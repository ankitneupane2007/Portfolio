# Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my skills, services, projects, and web development journey.

## About the Project

This portfolio represents **Ankit Neupane**, a web developer focused on creating clean, responsive, interactive, and user-friendly web experiences.

The website includes multiple sections to introduce myself, showcase my skills and services, display selected projects, and provide visitors with a way to get in touch.

# JavaScript Features

The project includes several interactive features.

## Mobile Navigation

A responsive menu allows navigation on smaller screens.

## Changing Roles

The hero section automatically cycles through roles such as:

* Web Developer
* Designer
* Freelancer

## Dynamic Year

The footer automatically displays the current year.

## Back to Top

A button appears after scrolling and smoothly returns the user to the top of the page.

## Parallax Effect

The parallax section responds to scrolling to create a more dynamic visual experience.

## Contact Form Animation

The submit button changes its state to provide visual feedback when a visitor submits the form.
